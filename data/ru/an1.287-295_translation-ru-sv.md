*Ангуттара Никая 1*

*23\. Третья глава*

287

«Монахи, не может быть такого, немыслимо, чтобы нежелательный, нежеланный, неприятный результат мог бы произойти из благого телесного поведения\. Нет такой возможности\. Но может быть так, что желаемый, желанный, приятный результат произойдёт из благого телесного поведения\. Есть такая возможность»\.

288\-289

«Монахи, не может быть такого, немыслимо, чтобы нежелательный, нежеланный, неприятный результат мог бы произойти из благого словесного…  благого умственного поведения\. Нет такой возможности\. Но может быть так, что желаемый, желанный, приятный результат произойдёт из благого словесного …  благого умственного поведения\. Есть такая возможность»\.

290

«Монахи, не может быть такого, немыслимо, чтобы человек, который пускается в неблагое телесное поведение, в этом случае, по этой причине, с распадом тела, после смерти, переродился в счастливом уделе, в небесном мире\. Нет такой возможности\. Но может быть так, что человек, который пускается в неблагое телесное поведение в этом случае, по этой причине, с распадом тела, после смерти, переродится в состоянии лишений, в несчастливом уделе, в нижних мирах, даже в аду\. Есть такая возможность»\.

Есть такая возможность»\.
