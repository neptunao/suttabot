*Ангуттара Никая 1*

*21\. Первая глава*

268

«Монахи, не может быть такого, немыслимо, чтобы человек, совершенный в воззрениях, мог бы считать какой\-либо обусловленный феномен постоянным\. Нет такой возможности\. Но может быть так, что обычный заурядный человек будет считать какой\-либо обусловленный феномен постоянным\. Есть такая возможность»\.

269

«Монахи, не может быть такого, немыслимо, чтобы человек, совершенный в воззрениях, мог бы считать какой\-либо обусловленный феномен приятным\. Нет такой возможности\. Но может быть так, что обычный заурядный человек будет считать какой\-либо обусловленный феномен приятным\. Есть такая возможность»\.

270

«Монахи, не может быть такого, немыслимо, чтобы человек, совершенный в воззрениях, мог бы считать какой\-либо феномен своим «я»\. Нет такой возможности\. Но может быть так, что обычный заурядный человек будет считать что\-либо своим «я»\. Есть такая возможность»\.

271

«Монахи, не может быть такого, немыслимо, чтобы человек, совершенный в воззрениях, мог бы намеренно лишить жизни свою мать\. Нет такой возможности\. Но может быть так, что обычный заурядный человек намеренно лишит жизни свою мать\. Есть такая возможность»\.

272

«Монахи, не может быть такого, немыслимо, чтобы человек, совершенный в воззрениях, мог бы намеренно лишить жизни своего отца\. Нет такой возможности\. Но может быть так, что обычный заурядный человек намеренно лишит жизни своего отца \. Есть такая возможность»\.

273

«Монахи, не может быть такого, немыслимо, чтобы человек, совершенный в воззрениях, мог бы намеренно лишить жизни араханта\. Нет такой возможности\. Но может быть так, что обычный заурядный человек намеренно лишит жизни араханта\. Есть такая возможность»\.

274

«Монахи, не может быть такого, немыслимо, чтобы человек, совершенный в воззрениях, мог бы с умом, полным ненависти, пролить кровь Татхагаты\. Нет такой возможности\. Но может быть так, что обычный заурядный человек с умом, полным ненависти, прольет кровь Татхагаты\. Есть такая возможность»\.

275

Монахи, не может быть такого, немыслимо, чтобы человек, совершенный в воззрениях, мог бы создать раскол в Сангхе\. Нет такой возможности\. Но может быть так, что обычный заурядный человек создаст раскол в Сангхе\. Есть такая возможность»\.

276

«Монахи, не может быть такого, немыслимо, чтобы человек, совершенный в воззрениях, мог бы признать кого\-либо другого кроме Будды учителем\. Нет такой возможности\. Но может быть так, что обычный заурядный человек признает кого\-либо другого \[кроме Будды учителем\. Есть такая возможность»\.

277

«Монахи, не может быть такого, немыслимо, чтобы два совершенных, полностью просветлённых, возникли бы в одно время в одной мировой системе\. Нет такой возможности\. Но может быть так, что один совершенный, полностью просветлённый, возникнет в одной мировой системе\. Есть такая возможность»\.
