*Ангуттара Никая 2*

*15\. Медитативные достижения*

163

«Монахи, есть эти два качества\. Какие два? Умение вхождения в медитативное достижение и умение выхода из медитативного достижения\. Таковы два качества»\.

164

«Монахи, есть эти два качества\. Какие два? Честность и доброта\. Таковы два качества»\.

165

«Монахи, есть эти два качества\. Какие два? Терпение и мягкость\. Таковы два качества»\.

166

«Монахи, есть эти два качества\. Какие два? Мягкость речи и гостеприимство\. Таковы два качества»\.

167

«Монахи, есть эти два качества\. Какие два Непричинение вреда и чистота\. Таковы два качества»\.

168

«Монахи, есть эти два качества\. Какие два? Отсутствие охраны дверей способностей органов чувств и неумеренность в еде\. Таковы два качества»\.

169

«Монахи, есть эти два качества\. Какие два? Охрана дверей способностей органов органов чувств и умеренность в еде\. Таковы два качества»\.

170

«Монахи, есть эти два качества\. Какие два? Сила размышления и сила развития\. Таковы два качества»\.

171

«Монахи, есть эти два качества\. Какие два? Сила осознанности и сила сосредоточения\. Таковы два качества»\.

172

«Монахи, есть эти два качества\. Какие два? Успокоение и прозрение\. Таковы два качества»\.

173

«Монахи, есть эти два качества\. Какие два? Неудача в нравственном поведении и неудача в воззрении\. Таковы два качества»\.

174

«Монахи, есть эти два качества\. Какие два? Успех в нравственном поведении и успех в воззрении Таковы два качества»\.

175

«Монахи, есть эти два качества\. Какие два? Чистота нравственного поведения и чистота воззрения\. Таковы два качества»\.

176

«Монахи, есть эти два качества\. Какие два? Чистота воззрения и старание в соответствии со своим воззрением\. Таковы два качества»\.

177

«Монахи, есть эти два качества\. Какие два? Не\-довольствование в плане благих качеств и неутомимость в старании\. Таковы два качества»\.

178

«Монахи, есть эти два качества\. Какие два? Замутнённость ума и отсутствие бдительности\. Таковы два качества»\.

179

«Монахи, есть эти два качества\. Какие два? Осознанность и бдительность\. Таковы два качества»\.
