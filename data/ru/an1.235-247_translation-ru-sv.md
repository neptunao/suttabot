*Ангуттара Никая 1*

*18\. Пятая глава*

«Монахи, самой выдающейся моей ученицей среди монахинь плане старшинства является Махападжапати Готами»\.

… которые обладают великой мудростью, является Кхема»\.

… которые обладают сверхъестественными силами, является Уппалаванна»\.

… которые являются поборниками Винаи, является Патачара»\.

… которые являются ораторами Дхаммы, является Дхаммадинна»\.

… которые медитируют, является Нанда»\.

… которые зарождают усердие, является Сона»\.

… которые обладают божественным глазом, является Сакула»\.

… которые быстро достигают прямого знания, является Бхадда Кундалакеса»\.

… которые вспоминают прошлые жизни, является Бхадда Капилани»\.

… которые достигают великого прямого знания, является Бхадда Каччана»\.

… которые носят грубые одежды, является Кисаготами»\.

… которые обрели решительность посредством веры, является Сигаламата»\.
