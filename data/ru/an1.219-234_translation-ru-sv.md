*Ангуттара Никая 1*

*17\. Четвертая глава*

«Монахи, самым выдающимся моим учеником среди монахов, которые учёные, является Ананда»\.

… которые обладают хорошей памятью, является Ананда»\.

… которые быстро схватывают учения, является Ананда»\.

… которые решительны, является Ананда»\.

… которые являются личными прислужниками, является Ананда»\.

… с большой свитой, является Урувела Кассапа»\.

… которые пробуждают доверие в семьях, является Калудайи»\.

… которые обладают хорошим здоровьем, является Баккула»\.

… которые вспоминают свои прошлые жизни, является Собхита»\.

… которые являются поборниками Винаи, является Упали»\.

… которые наставляют монахинь, является Нандака»\.

… которые лучше других охраняют двери способностей \[органов\] чувств, является Нанда»\.

… которые дают советы монахам, является Махакаппина»\.

… с умением в элементе огня, является Сагата»\.

… которым дают красноречивые проповеди, является Радха»\.

… которые носят грубые одежды, является Могхараджа»\.
