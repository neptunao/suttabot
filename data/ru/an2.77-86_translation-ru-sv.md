*Ангуттара Никая 2*

*8\. С основой*

77

«Монахи, плохие, неблагие качества возникают с основанием, а не без основания\. С отбрасыванием основания эти плохие, неблагие качества не происходят»\.

78

«Монахи, плохие, неблагие качества возникают через источник, а не без источника\. С отбрасыванием источника эти плохие, неблагие качества не происходят»\.

79

«Монахи, плохие, неблагие качества возникают через причину, а не без причины\. С отбрасыванием причины эти плохие, неблагие качества не происходят»\.

80

«Монахи, плохие, неблагие качества возникают через формирователи, а не без формирователей\. С отбрасыванием формирователей эти плохие, неблагие качества не происходят»\.

81

«Монахи, плохие, неблагие качества возникают с условием, а не без условия\. С отбрасыванием условия эти плохие, неблагие качества не происходят»\.

82

«Монахи, плохие, неблагие качества возникают вместе с материальной формой, а не без материальной формы\. С отбрасыванием материальной формы эти плохие, неблагие качества не происходят»\.

83

«Монахи, плохие, неблагие качества возникают вместе с чувством, а не без чувства\. С отбрасыванием чувства эти плохие, неблагие качества не происходят»\.

84

«Монахи, плохие, неблагие качества возникают вместе с восприятием, а не без восприятия\. С отбрасыванием восприятия эти плохие, неблагие качества не происходят»\.

85

«Монахи, плохие, неблагие качества возникают вместе с сознанием, а не без сознания\. С отбрасыванием сознания эти плохие, неблагие качества не происходят»\.

86

«Монахи, плохие, неблагие качества возникают, основываясь на обусловленном, не без основания в обусловленном\. С отбрасыванием обусловленного эти плохие, неблагие качества не происходят»\.
