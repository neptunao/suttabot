*Ангуттара Никая 1*

*22\. Вторая глава*

278

«Монахи, не может быть такого, немыслимо, чтобы два царя\-миродержца возникли бы в одно время в одной мировой системе\. Нет такой возможности\. Но может быть так, что один царь\-миродержец возникнет в одной мировой системе\. Есть такая возможность»\.

279

«Монахи, не может быть такого, немыслимо, чтобы женщина могла бы быть совершенной, полностью просветлённой\. Нет такой возможности\. Но может быть так, что мужчина станет совершенным, полностью просветлённым\. Есть такая возможность»\.

280

«Монахи, не может быть такого, немыслимо, чтобы женщина могла бы быть царём\-миродержцем\. Нет такой возможности\. Но может быть так, что мужчина станет царём\-миродержцем\. Есть такая возможность»\.

281\-283

«Монахи, не может быть такого, немыслимо, чтобы чтобы женщина могла бы занимать место Сакки … место Мары … место Брахмы\. Нет такой возможности\. Но может быть так, что мужчина займет место Сакки  … место Мары … место Брахмы\. Есть такая возможность»\.

284

«Монахи, не может быть такого, немыслимо, чтобы желаемый, желанный, приятный результат мог бы произойти из неблагого телесного поведения\. Нет такой возможности\. Но может быть так, что нежелательный, нежеланный, неприятный результат произойдёт из неблагого телесного поведения\. Есть такая возможность»\.

285\-286

«Монахи, не может быть такого, немыслимо, чтобы желаемый, желанный, приятный результат мог бы произойти из неблагого словесного поведения … неблагого умственного поведения\. Нет такой возможности\. Но может быть так, что нежелательный, нежеланный, неприятный результат произойдёт из неблагого словесного поведения … неблагого умственного поведения\.\. Есть такая возможность»\.
