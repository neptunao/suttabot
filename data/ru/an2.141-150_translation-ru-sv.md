*Ангуттара Никая 2*

*13\. Дары*

141

«Монахи, есть эти два вида даров\. Какие два? Дар материальных благ и дар Дхаммы\. Таковы два вида даров\. Из этих двух видов даров дар Дхаммы является высочайшим»\.

142

«Монахи, есть эти два вида подношений\. Какие два? Подношение материальных благ и подношение Дхаммы\. Таковы два вида подношений\. Из этих двух видов подношений подношение Дхаммы является высочайшим»\.

143

«Монахи, есть эти два вида щедрости\. Какие два? Щедрость материальными благами и щедрость Дхаммой\. Таковы два вида щедрости\. Из этих двух видов щедрости щедрость Дхаммой является высочайшей»\.

144

«Монахи, есть эти два вида благотворительности\. Какие два? Благотворительность дарением материальных благ и благотворительность дарением Дхаммы\. Таковы два вида благотворительности\. Из этих двух видов благотворительности благотворительность дарением Дхаммы является высочайшей»\.

145

«Монахи, есть эти два вида богатства\. Какие два? Материальное богатство и богатство Дхаммы\. Таковы два вида богатства\. Из этих двух видов богатства богатство Дхаммы является высочайшим»\.

146

«Монахи, есть эти два вида наслаждения\. Какие два? Наслаждение материальными благами и наслаждение Дхаммой\. Таковы два вида наслаждений\. Из этих двух видов наслаждения наслаждение Дхаммой является высочайшим»\.

147

«Монахи, есть эти два вида разделения\. Какие два? Разделение материальных благ и разделение Дхаммы\. Таковы два вида разделения\. Из этих двух видов разделения разделение Дхаммы является высочайшим»\.

148

«Монахи, есть эти два вида поддержания благоприятных отношений\. Какие два? Поддержания благоприятных отношений материальными благами и делание этого Дхаммой\. Таковы два вида поддержания благоприятных отношений\. Из этих двух способов поддержание благоприятных отношений Дхаммой является высочайшим»\.

149

«Монахи, есть эти два вида содействия\. Какие два? Содействие материальными благами и содействие Дхаммой\. Таковы два вида содействия\. Из этих двух видов содействия содействие Дхаммой является высочайшим»\.

150

«Монахи, есть эти два вида сострадания\. Какие два? Сострадание, проявленное материальными благами, и сострадание, проявленное Дхаммой\. Таковы два вида сострадания\. Из этих двух видов сострадания сострадание, проявленное Дхаммой, является высочайшим»\.
